# Empath VR

Empath VR is a web-based project related to Virtual Reality (VR) therapy.  
The application provides information about VR-based therapy, a community page, and a feedback system where users can share their thoughts.

This project is a basic full-stack web application developed using frontend and backend technologies.

---

## About the Project

Mental health conditions such as anxiety, stress, and phobias are often treated using exposure therapy. Virtual Reality (VR) therapy is a modern approach that allows controlled and safe exposure through virtual environments.

Empath VR was created to:
- Share information about VR therapy
- Provide a simple community interface
- Allow users to submit feedback and suggestions
- Demonstrate frontend and backend communication
---

## Features

- Homepage with project overview  
- Whitepaper and research section  
- Community page for discussions and feedback  
- Feedback form to submit user suggestions  
- Backend API to store and retrieve feedback

## How the Project Works

1. The user opens the website using the homepage file.
2. Navigation links allow the user to access the whitepaper and research, community, and FAQ pages.
3. On the Community page, the user enters feedback in a form.
4. When the form is submitted, JavaScript sends the data to the backend server using an API request.
5. The backend server receives the feedback and stores it.
6. The server then sends all stored feedback back to the frontend.
7. The frontend displays the feedback on the Community page.

This process demonstrates how a frontend interface communicates with a backend server.
